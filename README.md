# Sales Analysis Dashboard
## Project Overview
An interactive sales analysis dashboard developed using Microsoft Power BI to explore business performance and profitability.
## Objectives
- Analyze overall sales performance.
- Monitor sales and profit.
- Compare product-wise and region-wise sales.
- Analyze salesperson performance.
- Explore monthly sales and profit trends.
## Tools
- Microsoft Power BI
## Dashboard Features
- Total Sales
- Total Profit (estimated)
- Profit Margin (estimated)
- Total Orders
- Average Order Value
- Product-wise sales analysis
- Region-wise sales analysis
- Salesperson performance
- Monthly sales and profit trends
- Region manager map

## Profit Calculation
The report assumes product cost is 65% of list price. Therefore, profit and profit margin are estimates based on this assumption.
## Project Files
- Dashboard/Sales_Dashboard.pbix
## Disclaimer
Profit and profit margin are estimates calculated using an assumed product cost of 65% of list price. These figures should not be interpreted as actual verified business profit.
